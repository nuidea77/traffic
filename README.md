# 🚗 Түгжрэл тойрох маршрут — Улаанбаатар

Түгжрэлтэй үед **гэр хороолол болон хорооллын доторх жижиг туслах замуудыг**
ашиглан хамгийн хурдан явах маршрутыг гаргадаг вэб апп.

## Хэрхэн ажилладаг вэ?

Ердийн навигацын аппууд гол замын дагуух маршрутыг санал болгодог ч оргил
ачааллын үед Улаанбаатарын гол замууд (Энхтайваны өргөн чөлөө, Чингисийн
өргөн чөлөө г.м.) мөлхөж, харин гэр хороолол болон хорооллын доторх жижиг
замууд харьцангуй чөлөөтэй байдаг.

Энэ апп үүнийг дараах байдлаар шийддэг:

1. **Замын сүлжээ** — Сонгосон хоёр цэгийг багтаасан хүрээний бүх машины
   замыг OpenStreetMap-аас (Overpass API) татаж граф байгуулна. Гэр
   хорооллын жижиг замууд (`residential`, `service`, `unclassified`,
   `track`) бүгд орно.
2. **Түгжрэлийн загвар** — Замын ангилал бүрд суурь хурд, түгжрэлийн
   түвшин бүрд хурдны коэффициент оноодог:

   | Түвшин | Гол зам (trunk/primary) | Дунд зам (secondary/tertiary) | Жижиг/хорооллын зам |
   |---|---|---|---|
   | 🟢 Чөлөөтэй | 100% | 100% | 100% |
   | 🟡 Хэвийн | 75% | 85% | 95% |
   | 🟠 Ачаалалтай | 40% | 60% | 85% |
   | 🔴 Түгжрэлтэй | **18%** | 35% | **75%** |

   Шороон замын хурдыг нэмж бууруулдаг, уулзвар бүрд эргэлтийн саатал
   тооцдог тул жижиг замаар зигзаг хийхийн бодит өртөг тусгагдана.
3. **A\* хайлт** — Ирмэг бүрийн туулах *хугацааг* жин болгон A\* алгоритм
   ажиллуулна. Түгжрэлтэй үед гол замын хугацаа огцом өсдөг тул алгоритм
   өөрөө хорооллын жижиг замаар тойрсон хамгийн хурдан маршрутыг олдог.
4. **Харьцуулалт** — Ухаалаг маршрутыг энгийн (гол замын) маршруттай
   зэрэгцүүлж, одоогийн түгжрэлээр хэдэн минут хэмнэхийг харуулна.

「🕐 Одоогийн цагаар」горимд Улаанбаатарын цагаар ажлын өдрийн
07:30–10:00 ба 16:30–20:00 цагийг түгжрэлтэй гэж автоматаар тооцно.

## Ажиллуулах

Build шаардлагагүй, цэвэр static сайт:

```bash
python3 -m http.server 8000
# эсвэл: npx serve
```

Дараа нь хөтчөөр <http://localhost:8000> нээнэ. (Overpass, Nominatim,
OSM tile серверүүдэд хандах интернэт холболт шаардлагатай.)

## Ашиглах

1. Газрын зураг дээр дарж (эсвэл хайлтаар) эхлэх 🟢 ба очих 🔴 цэгээ сонго
2. Түгжрэлийн түвшнээ сонго (эсвэл「Одоогийн цагаар」үлдээ)
3. **「Маршрут гаргах」** дар
4. Ногоон шугам = түгжрэл тооцсон ухаалаг маршрут, саарал тасархай
   шугам = энгийн гол замын маршрут

## Файлын бүтэц

| Файл | Үүрэг |
|---|---|
| `index.html` | UI бүтэц |
| `css/style.css` | Загвар |
| `js/graph.js` | Overpass-аас зам татах, граф байгуулах |
| `js/router.js` | Түгжрэлийн жинтэй A* алгоритм |
| `js/app.js` | Газрын зураг, UI, маршрутын харьцуулалт |

## Хязгаарлалт

- Түгжрэлийн загвар нь бодит цагийн мэдээлэл биш, замын ангилалд
  суурилсан статистик таамаглал юм.
- Overpass API-гийн ачааллаас шалтгаалж эхний татах хэдэн секунд үргэлжилж
  болно; нэг хүрээний өгөгдлийг кэшлэдэг тул түвшин солиход шууд бодогдоно.
- Хэт урт (>28 км хүрээ) маршрутыг Overpass-ийн ачааллын үүднээс хязгаарласан.

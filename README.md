# 🚗 Түгжрэл тойрох маршрут — Улаанбаатар

Түгжрэлтэй үед **гэр хороолол болон хорооллын доторх жижиг туслах замуудыг**
ашиглан хамгийн хурдан явах маршрутыг гаргадаг апп. Вэб хувилбараас гадна
[Capacitor](https://capacitorjs.com)-оор бүтээсэн **iOS болон Android**
нэйтив апп болгон build хийж болно.

## Хэрхэн ажилладаг вэ?

Ердийн навигацын аппууд гол замын дагуух маршрутыг санал болгодог ч оргил
ачааллын үед Улаанбаатарын гол замууд (Энхтайваны өргөн чөлөө, Чингисийн
өргөн чөлөө г.м.) мөлхөж, харин гэр хороолол болон хорооллын доторх жижиг
замууд харьцангуй чөлөөтэй байдаг.

Энэ апп үүнийг дараах байдлаар шийддэг:

1. **Замын сүлжээ** — Сонгосон хоёр цэгийг багтаасан хүрээний бүх машины
   замыг OpenStreetMap-аас (Overpass API) татаж граф байгуулна. Гэр
   хорооллын жижиг замууд (`residential`, `service`, `unclassified`,
   `track`) бүгд орно.
2. **🤖 AI түгжрэлийн загвар** — (гараг, цаг, замын ангилал) →
   хурдны харьцаа таамагладаг неорон сүлжээ (MLP: 8 → 24 → 12 → 1).
   Python дээр сургаж жингүүдийг JSON болгон экспортлоод апп дотор
   JS-ээр inference хийдэг тул сервер шаардлагагүй, офлайн ажиллана.
   Жишээ таамаглал (Даваа гараг):

   | Цаг | Гол зам | Дунд зам | Жижиг/хорооллын зам |
   |---|---|---|---|
   | 03:00 | 98% | 98% | 98% |
   | 08:30 | 31% | 45% | 75% |
   | 13:00 | 73% | 78% | 90% |
   | 18:15 | **21%** | 36% | **71%** |

   Хэрэглэгч түвшнээ гараар сонговол тогтмол коэффициентийн fallback
   хүснэгт ашиглана. Шороон замын хурдыг нэмж бууруулдаг, уулзвар бүрд
   эргэлтийн саатал тооцдог тул жижиг замаар зигзаг хийхийн бодит
   өртөг тусгагдана.
3. **A\* хайлт** — Ирмэг бүрийн туулах *хугацааг* жин болгон A\* алгоритм
   ажиллуулна. Түгжрэлтэй үед гол замын хугацаа огцом өсдөг тул алгоритм
   өөрөө хорооллын жижиг замаар тойрсон хамгийн хурдан маршрутыг олдог.
4. **Харьцуулалт** — Ухаалаг маршрутыг энгийн (гол замын) маршруттай
   зэрэгцүүлж, одоогийн түгжрэлээр хэдэн минут хэмнэхийг харуулна.

「🤖 AI (одоогийн цагаар)」горимд загвар УБ-ын цагаар одоогийн
гараг/цагийн түгжрэлийг таамаглаж тасралтгүй коэффициент гаргана.

## 🧠 Machine learning цикл

```
ml/generate_data.py ──► ml/data/*.csv ──► ml/train.py ──► www/model/traffic_model.json
        ▲                    ▲                                      │
        │                    │ (бодит хэмжилт нэмэх)                ▼
   УБ-ын хэв маягийн    апп доторх 🚙 горимын              js/model.js (JS inference)
   синтетик seed өгөгдөл   CSV экспорт                      + локал calibration
```

1. **Сургалт** (Python + numpy, өөр хамаарал байхгүй):

   ```bash
   pip install numpy
   npm run ml:data    # УБ-ын хэв маягт суурилсан 60k мөр seed өгөгдөл
   npm run ml:train   # MLP сургаад www/model/traffic_model.json экспортолно
   ```

2. **Бодит өгөгдөл цуглуулах** — аппын 🚙「Хэмжилт эхлүүлэх」товч
   жолоодох үед GPS хурдыг ойролцоох замын ангилалтай тулгаж
   `speed_ratio` хэмжилт хуримтлуулна. Энэ нь:
   - **Шууд** — локал calibration: таны явдаг замын бодит байдалд
     загварын таамаглалыг аажмаар тааруулна (хэмжилт олширвол 50%
     хүртэл жинтэй холино, төхөөрөмж дээрээ хадгална).
   - **Урт хугацаанд** —「⬇ CSV экспорт」-оор татаж `ml/data/`-д
     хийгээд `npm run ml:train` ажиллуулбал загвар бодит өгөгдлөөр
     дахин сурна. Синтетик болон бодит CSV ижил схемтэй.

3. **Parity баталгаа** — train.py жишиг таамаглалуудыг
   `ml/reference_preds.json`-д хадгалдаг тул JS inference Python-той
   зөрөхгүй байгааг тестээр шалгаж болно.

## Вэб хувилбар ажиллуулах

Build шаардлагагүй, цэвэр static сайт (`www/` хавтаст):

```bash
npm run serve
# эсвэл: python3 -m http.server 8000 --directory www
```

Дараа нь хөтчөөр <http://localhost:8000> нээнэ. (Overpass, Nominatim,
OSM tile серверүүдэд хандах интернэт холболт шаардлагатай.)

## 📱 Android апп build хийх

Шаардлага: [Android Studio](https://developer.android.com/studio)
(эсвэл Android SDK + JDK 21).

```bash
npm install
npx cap sync android

# Android Studio-гоор нээх:
npx cap open android

# эсвэл шууд командын мөрөөс APK build хийх:
cd android && ./gradlew assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

Утсаа USB-ээр залгаад `npx cap run android` гэвэл шууд суулгаж ажиллуулна.

## 📱 iOS апп build хийх

Шаардлага: macOS, [Xcode](https://developer.apple.com/xcode/), CocoaPods
(`sudo gem install cocoapods`).

```bash
npm install
npx cap sync ios   # pod install-ийг автоматаар хийнэ
npx cap open ios   # Xcode-оор нээгээд ▶ Run
```

Бодит төхөөрөмж дээр ажиллуулахад Apple Developer бүртгэлээр signing
тохируулах шаардлагатай (Xcode → Signing & Capabilities).

### Нэйтив аппын нэмэлт боломж

- 📍 товч — GPS-ээр одоогийн байршлаа эхлэх цэг болгоно
  (Capacitor Geolocation plugin, зөвшөөрлүүд Android manifest болон
  iOS Info.plist-д нэмэгдсэн)
- Leaflet библиотек локал (`www/vendor/`) багтсан тул CDN-ээс хамаарахгүй

Вэб кодыг (`www/`) өөрчилсний дараа `npx cap sync` ажиллуулж native
төслүүдэд хуулахаа мартав.

## Ашиглах

1. Газрын зураг дээр дарж (эсвэл хайлтаар) эхлэх 🟢 ба очих 🔴 цэгээ сонго
2. Түгжрэлийн түвшнээ сонго (эсвэл「Одоогийн цагаар」үлдээ)
3. **「Маршрут гаргах」** дар
4. Ногоон шугам = түгжрэл тооцсон ухаалаг маршрут, саарал тасархай
   шугам = энгийн гол замын маршрут

## Бодит замын өгөгдөл

Апп ажиллах үедээ **Монголын жинхэнэ замуудыг** ашигладаг:

- **Замын сүлжээ** — Overpass API-аас Улаанбаатарын OSM замууд
  (гэр хорооллын шороон зам хүртэл) бодит цагт татагдана
- **Газрын зураг** — CARTO dark / OpenStreetMap tile
- **Хайлт** — Nominatim (OSM-ийн хаягийн сан)

Тиймээс интернэттэй ямар ч орчинд нээхэд жинхэнэ УБ-ын зураг, зам гарна.
Бодит өгөгдөлтэй скриншотыг автоматаар авахын тулд:

```bash
npm i -D playwright && npx playwright install chromium
npm run shots        # Сүхбаатарын талбай → Дари-Эх, жинхэнэ замаар
npm run shots:demo   # офлайн синтетик демо (сүлжээгүй орчинд)
```

## Хязгаарлалт

- AI загвар одоогоор УБ-ын түгжрэлийн хэв маягт суурилсан синтетик
  өгөгдлөөр сургагдсан — бодит цагийн мэдээлэл биш, гараг/цагийн
  статистик таамаглал юм. 🚙 горимоор бодит хэмжилт цуглуулж дахин
  сургах тусам бодит байдалд ойртоно.
- Overpass API-гийн ачааллаас шалтгаалж эхний татах хэдэн секунд үргэлжилж
  болно; нэг хүрээний өгөгдлийг кэшлэдэг тул түвшин солиход шууд бодогдоно.
- Хэт урт (>28 км хүрээ) маршрутыг Overpass-ийн ачааллын үүднээс хязгаарласан.
